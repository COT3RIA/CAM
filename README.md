# CAM by COTERIA (VST3)

Плагин показывает веб-камеру в своём окне внутри DAW, умеет записывать видео (с микрофоном, со звуком мастер-шины
DAW или без звука), стартовать запись вместе с Play в DAW, сам называть файлы, имитировать объективы и работает на
русском и английском. Аудио проходит через плагин без изменений.

## Сборка через GitHub

1. Создайте репозиторий на GitHub и залейте в него содержимое проекта (структуру папок не менять).
2. Откройте вкладку **Actions**, дождитесь окончания сборки (первая занимает 5-10 минут).
3. В разделе **Artifacts** скачайте установщик (`CAM-Installer-Windows` или `CAM-Installer-macOS`)
   либо «голые» файлы плагина (`CAM-Windows` / `CAM-macOS`).

## Установка без установщика

- **Windows:** папку `CAM.vst3` в `C:\Program Files\Common Files\VST3`, затем пересканируйте плагины в DAW.
- **macOS:** `CAM.vst3` в `/Library/Audio/Plug-Ins/VST3`. Если macOS блокирует плагин после скачивания:
  `xattr -cr "/Library/Audio/Plug-Ins/VST3/CAM.vst3"`

Если раньше стоял плагин под именем «Webcam Viewer», удалите `Webcam Viewer.vst3` из папки VST3, иначе
в DAW будет две копии. Установщик для Windows удаляет старую версию сам.

Standalone-версия удобна, чтобы проверить камеру и микрофон без DAW.

## Окно плагина

Видео занимает всё окно. Панель настроек и строка статуса появляются поверх видео, когда курсор над плагином,
и плавно прячутся, когда курсор ушёл. Индикатор записи (REC) виден всегда.

**Элементы панели:** камера, объектив (13 / 24 / 35 / 48 / 50 / 77 / 85 / 135 мм, «рыбий глаз», подушка, кино 2.39:1, тилт-шифт), зеркало, запись, папка с записями,
источник звука (выкл / микрофон / мастер DAW), режим записи звука, сдвиг звука (только для звука DAW),
«С транспортом DAW», название проекта, переключатель языка (русский / English). Кнопки сами переносятся на
несколько строк, лишние настройки прячутся. Язык по умолчанию берётся из системы и сохраняется вместе с проектом DAW.

## Цветовые фильтры

Список «Без фильтра / Чёрно-белое / Сепия / Тёплый тон / Холодный тон / Контраст / VHS» и отдельные галочки «Виньетка» и
«Зерно» (их можно включать вместе с любым фильтром). Фильтр виден в окне и **вшивается в запись в режиме «Вместе с видео (AVI)»**.
Запись камеры в WMV/MOV (звук выключен или режим «Отдельным файлом») идёт мимо плагина, поэтому фильтров в ней нет.
Объективы и зеркало по-прежнему только в окне. Фильтры считаются на процессоре, при камере 720p нагрузка небольшая.

## Индикаторы звука

Кнопка «Индикаторы» в панели открывает список эффектов с галочками. Включить можно любые сразу, либо «Выключить все».
По умолчанию включён первый.

| Эффект | Что показывает |
|---|---|
| Метр с подписью (DAW / микрофон) | Плашка слева внизу: значок и подпись «DAW» (треугольник Play) или «MIC» (микрофон) по выбранному источнику звука и стерео-метр. Гаснет, когда курсор ушёл, и появляется при наведении |
| Мини-метр у REC | Две полоски в плашке REC во время записи |
| Точка состояния звука | В плашке REC: зелёная = звук идёт, красная мигающая = звука от DAW нет, серая = ждёт |
| Волна по нижнему краю | Полупрозрачная волна вдоль нижней кромки кадра, гаснет вместе с панелью |
| Пульсация точки REC | Красная точка в плашке REC меняет размер и яркость в такт громкости |

Метр зелёный, на громких пиках жёлтый, при перегрузке (0 дБ) красный. Плашка REC видна всегда, остальное гаснет без курсора.
Источник «DAW» показывает уровень и вне записи, пока в DAW что-то играет. Источник «Микрофон» показывает уровень только во время
записи: микрофон не открывается заранее, чтобы не держать его без необходимости. Индикаторы в записанный файл не попадают.

## Запись

Файлы сохраняются в папку `Movies/CAM` (кнопка «Папка» открывает её).

| Настройка | Что получится |
|---|---|
| Звук: выкл | Только видео: `.wmv` (Windows) или `.mov` (macOS), пишет сама камера |
| Звук включён, «Вместе с видео (AVI)» | Один файл `.avi` (видео MJPEG + звук PCM) |
| Звук включён, «Отдельным файлом (WAV)» | Видео `.wmv` / `.mov` и рядом звук `.wav` с тем же именем |

Микрофон можно выбрать из списка или оставить «по умолчанию».

## Синхронизация с транспортом DAW

Включите «С транспортом DAW»: запись стартует, когда в проекте нажали Play, и останавливается на Stop.
Кнопкой «Запись» по-прежнему можно записывать вручную (такая запись по Stop не останавливается).
Если Play уже идёт в момент включения, запись не стартует: нужен новый запуск воспроизведения.
Окно плагина при этом должно быть открыто (камера живёт в окне плагина).

## Звук из DAW вместо микрофона

Выберите «Звук: мастер DAW». Плагин пишет то, что DAW подаёт ему на вход, в стерео. **Поставьте CAM на мастер-канал**
(последним в цепочке эффектов), тогда в запись попадёт весь проект, и сниппет с битом получается за один дубль:
видео и звук лежат в одном AVI. Звук проходит через плагин без изменений, так что слышно всё как обычно.

**Сдвиг звука (оффсет, мс):** камера отдаёт кадр с задержкой, а DAW может компенсировать задержку плагинов, поэтому звук
и картинка могут разойтись. Положительное значение сдвигает звук **позже** (в начало добавляется тишина), отрицательное
**раньше** (начало звука отбрасывается). Подбирается один раз на глаз: хлопните в ладоши или запишите метроном и
посмотрите в плеере, затем меняйте значение с шагом 5 мс. Если DAW остановили, а запись идёт, в звук добавляется тишина,
и видео со звуком не расходятся.

## Имя файла

Файл называется автоматически: `<проект>_<BPM>bpm_<дата>`, например `Мой_бит_140bpm_2026-11-27_09-15-30.avi`.
- **BPM** берётся из транспорта DAW (если DAW его не сообщает, часть опускается).
- **Проект:** если заполнено поле «Проект» в панели плагина, берётся оно. Иначе на Windows плагин пробует прочитать
  название из заголовка окна DAW (работает, если DAW пишет проект в заголовок, например `Мой бит - FL Studio`).
  VST3 не даёт плагину название проекта напрямую, поэтому это лучшая попытка; на macOS автоопределения нет,
  используйте поле. Если название не найдено, подставляется `CAM`.
- Если файл с таким именем уже есть, добавляется `_2`, `_3` и т. д.

## Важные ограничения

- Веб-камера не умеет менять оптику, поэтому объективы эмулируются программно: зум 24-135 мм это цифровой кроп
  центра кадра (от 1.5x до 6.5x), чем сильнее зум, тем ниже чёткость. «Рыбий глаз» (бочка) и «Подушка» это искажения,
  «Кино 2.39:1» добавляет чёрные полосы сверху и снизу, «Тилт-шифт» оставляет резкой центральную полосу и размывает верх и низ.
- Объектив и зеркало применяются только к картинке в окне. **В записанный файл попадает исходное видео с камеры.**
- **AVI (режим «Вместе с видео»):** формат MJPEG без сжатия между кадрами, поэтому файлы большие
  (порядка 100-200 МБ в минуту при 720p). Длинная запись автоматически делится на части по ~1.8 ГБ
  (`_part2`, `_part3`...), кадры при этом не теряются. AVI открывается в VLC, видеоредакторах
  (DaVinci Resolve, Premiere и др.); встроенный QuickTime Player на Mac такой файл, скорее всего, не откроет.
- **Звук DAW:** в режиме «Отдельным файлом (WAV)» звук DAW пишется в стерео WAV, остаточный сдвиг относительно видео
  камеры убирается оффсетом. Если от DAW звук не приходит (плагин не на мастере, хост не вызывает обработку),
  через 2 секунды записи в строке статуса появится подсказка. В Standalone-версии DAW нет, там звук DAW и транспорт не работают.
- **Отдельный WAV:** звук начинает писаться сразу после запуска записи видео камерой. Но камера сама начинает
  писать файл с небольшой задержкой, которую плагин не видит, поэтому при монтаже возможен остаточный сдвиг
  (обычно доли секунды). Для точной синхронизации используйте режим «Вместе с видео (AVI)».
- Запись и камера работают, пока открыто окно плагина. Закрыли окно: запись остановится, камера освободится.
- Камеру и микрофон плагину отдаёт хост. На macOS у DAW должно быть разрешение на камеру и микрофон,
  на Windows включите доступ к микрофону для классических приложений в параметрах конфиденциальности.
  Если камера не даёт картинку, в окне будет подсказка.
- Микрофон открывается напрямую через систему (а не через маршрутизацию DAW), поэтому звук DAW через микрофон
  в запись не попадает: для этого есть режим «Звук: мастер DAW».
