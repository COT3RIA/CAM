# Webcam Viewer (VST3)

Плагин показывает веб-камеру в своём окне внутри DAW, умеет записывать видео и имитировать объективы.
Аудио проходит через плагин без изменений.

## Сборка через GitHub

1. Создайте репозиторий на GitHub и залейте в него содержимое этого архива (структуру папок не менять).
2. Откройте вкладку **Actions**, дождитесь окончания сборки (первая занимает 5-10 минут).
3. Внизу страницы запуска, в разделе **Artifacts**, скачайте `WebcamViewer-Windows` или `WebcamViewer-macOS`.

## Установка

- **Windows:** скопируйте папку `Webcam Viewer.vst3` в `C:\Program Files\Common Files\VST3`, затем пересканируйте плагины в DAW.
- **macOS:** скопируйте `Webcam Viewer.vst3` в `/Library/Audio/Plug-Ins/VST3` (или `~/Library/Audio/Plug-Ins/VST3`).
  Если macOS блокирует плагин после скачивания, выполните в Терминале:
  `xattr -cr "/Library/Audio/Plug-Ins/VST3/Webcam Viewer.vst3"`

В артефактах также лежит Standalone-версия: удобно проверить камеру без DAW.

## Функции

- Выбор камеры из списка, зеркалирование.
- Объективы: 13mm (весь кадр), 24mm, 48mm, 77mm, Fisheye.
- Запись видео кнопкой Record. Файлы сохраняются в папку `Movies/WebcamViewer`
  (Windows: `.wmv`, macOS: `.mov`). Кнопка Open folder открывает эту папку.
- Выбранные камера, объектив и зеркалирование сохраняются вместе с проектом DAW.

## Важные ограничения

- Веб-камера не умеет менять оптику, поэтому объективы эмулируются программно:
  зум 24/48/77mm = цифровой кроп центра кадра (1.5x / 2.5x / 4x), Fisheye = искажение изображения.
  Чем сильнее зум, тем ниже чёткость.
- Эффект объектива и зеркало применяются только к картинке в окне. **В записанный файл попадает исходное видео с камеры.**
- Запись и камера работают, пока открыто окно плагина. Закрыли окно: запись остановится, камера освободится.
- На macOS доступ к камере зависит от разрешений DAW (хост должен иметь право на камеру,
  иначе в окне будет "No video received"). Некоторые DAW камеру для плагинов не отдают.
